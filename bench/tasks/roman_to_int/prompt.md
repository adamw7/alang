Convert a Roman numeral to an integer.

`s` is a valid Roman numeral in standard form for a number from 1 to 3999, using the symbols
I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 and M = 1000, and the subtractive pairs
IV = 4, IX = 9, XL = 40, XC = 90, CD = 400 and CM = 900. For example "MCMXCIV" is 1994.

`s` has at most 15 bytes.
