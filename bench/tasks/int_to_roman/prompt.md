Convert an integer from 1 to 3999 to a Roman numeral in standard form.

Use the symbols I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 and M = 1000, and the subtractive pairs
IV = 4, IX = 9, XL = 40, XC = 90, CD = 400 and CM = 900; never repeat a symbol more than three times.
For example 1994 is "MCMXCIV" and 3888 is "MMMDCCCLXXXVIII".
